Discord Tickets is fully internationalised. All bot messages, button labels, command descriptions, and modal prompts are loaded from YAML locale files at startup. The bot selects the appropriate locale for each guild based on the guild's configured language setting.

## How locales are loaded

Locale files live in `src/i18n/` as YAML files named after their locale code (e.g. `fr.yml`, `zh-CN.yml`). The bot loads all files in this directory at startup and makes them available through `client.i18n`.

The `/api/locales` endpoint exposes the list of available locales to the web dashboard:

```
GET /api/locales
```

This allows the settings UI to populate the language selector dynamically based on what is actually available at runtime.

## Setting a guild language

Each guild can independently set its locale via the settings dashboard or the `PATCH /api/admin/guilds/:guild/settings` endpoint. The `locale` field accepts any locale code from the list above.

Once set, all bot-generated messages in that guild — including ticket open messages, button labels, modal titles, and slash command descriptions — use that locale.

## Fallback behaviour

If a translation key is missing in a locale file, the bot falls back to `en-US`. This ensures that partially-translated locales do not cause errors.
