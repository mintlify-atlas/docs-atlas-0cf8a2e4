## What is Discord Tickets?

Discord Tickets is a free, open-source ticket management bot for Discord servers. It provides a complete support ticketing system with a rich web dashboard, slash commands, automated workflows, and detailed transcripts — all self-hosted on your own infrastructure.

Trusted by thousands of Discord servers and used to create over **half a million tickets** since 2019, Discord Tickets is the community's go-to alternative to paid ticketing bots.

<Note>
  Discord Tickets is licensed under the **GPL-3.0** license. The source code is available on [GitHub](https://github.com/discord-tickets/bot).
</Note>

## Quick start

<Steps>
  <Step title="Create a Discord application">
    Go to the [Discord Developer Portal](https://discord.com/developers/applications) and create a new application. See [Create a bot application](/getting-started/create-bot) for detailed steps.
  </Step>
  <Step title="Deploy the bot">
    Deploy using [Docker](/self-hosting/installation/docker) (recommended) or [manually](/self-hosting/installation/manual) on your server.
  </Step>
  <Step title="Configure environment variables">
    Set the required environment variables including `DISCORD_TOKEN`, `DISCORD_SECRET`, `ENCRYPTION_KEY`, and database settings. See [Configuration](/self-hosting/configuration).
  </Step>
  <Step title="Set up your first category">
    Open the web dashboard and create your first ticket category with custom questions and permissions. See [First category](/getting-started/first-category).
  </Step>
  <Step title="Invite the bot to your server">
    Generate an invite URL and add the bot to your Discord server. See [Invite the bot](/getting-started/invite).
  </Step>
</Steps>
