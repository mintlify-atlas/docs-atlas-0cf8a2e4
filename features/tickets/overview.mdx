title: "Ticketing system overview"
description: "How Discord Tickets organises support conversations into private, categorised channels."
---

Discord Tickets turns every support request into a dedicated Discord text channel. Each ticket is private to the person who created it and the staff roles assigned to its category, keeping conversations focused and auditable.

## How tickets work

When a user opens a ticket, the bot creates a new text channel inside a Discord category. The channel name is generated from a configurable template — for example `support-eartharoid-42` — and the channel topic shows the creator's mention and, if provided, the ticket topic.

The opening message is pinned automatically so context is always visible at the top of the channel. Staff are pinged via the roles configured for that category, and the user receives a confirmation embed with a link to the new channel.

If your server has only one category, users are sent directly to that category when they request a new ticket. If there are multiple categories, users see a select menu to choose the appropriate one.

## Ticket lifecycle

<Steps>
  <Step title="Created">
    A user triggers ticket creation via a button, select menu, or the `/new` command. The bot checks limits, required roles, and cooldowns, then creates the channel.
  </Step>
  <Step title="Open">
    Staff and the user communicate inside the ticket channel. Staff can add or remove members, set priority, claim the ticket, and more.
  </Step>
  <Step title="Close requested">
    Either the user or a staff member requests closure. If the category has feedback enabled and the user hasn't rated yet, they are prompted first.
  </Step>
  <Step title="Closed">
    After acceptance, the ticket channel is deleted. The bot sends a summary DM to the ticket creator and logs the event to the configured log channel.
  </Step>
</Steps>

## Key limits

| Constraint | Description |
|---|---|
| Total limit | Maximum open tickets per category |
| Member limit | Maximum open tickets per user per category |
| Cooldown | Minimum time between ticket creations per user per category |
| Discord category limit | A Discord category can hold at most 50 channels |

<Note>
All sensitive ticket data — topics, question answers, and close reasons — is encrypted at rest.
</Note>
